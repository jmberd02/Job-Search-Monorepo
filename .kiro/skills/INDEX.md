# Superpowers Skill Index

These skills define workflows the agent can use when solving problems.

When a task matches a skill description, load the skill folder and follow the instructions in its SKILL.md file.

---

## Core Development Workflow

brainstorming  
Used to generate multiple possible approaches before planning.

writing-plans  
Creates a detailed step-by-step implementation plan.

executing-plans  
Implements the plan one task at a time.

verification-before-completion  
Ensures requirements are met before finishing.

finishing-a-development-branch  
Handles cleanup and final integration.

---

## Debugging

systematic-debugging  
Structured process for diagnosing and fixing bugs.

---

## Quality & Review

test-driven-development  
Write tests before implementation.

requesting-code-review  
Prepare code for review.

receiving-code-review  
Incorporate review feedback.

---

## Advanced Workflows

dispatching-parallel-agents  
Split large work across multiple agents.

subagent-driven-development  
Delegate tasks to specialized subagents.

using-git-worktrees  
Use worktrees for parallel development.

writing-skills  
Create new reusable skills.

using-superpowers  
Explains how the Superpowers system works.
